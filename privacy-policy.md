# Privacy Policy for Twitch Superbar

**Effective Date:** February 14, 2026

## 1. Data Collection
Twitch Superbar ("the Extension") accesses the user's existing authentication token (`auth-token`) stored in the browser's cookies for the domain `twitch.tv`.

## 2. Data Usage
The authentication token is used solely for the purpose of making authorized requests to the official Twitch GQL API (`gql.twitch.tv`). These requests are necessary to retrieve the user's list of live followed channels, which is the primary functionality of the Extension.

## 3. Data Storage and Sharing
- **No Storage:** The Extension does not store the authentication token or any user data in permanent storage (such as `chrome.storage` or external databases). The token is read ephemerally when the script runs.
- **No Third-Party Sharing:** The authentication token is transmitted only to Twitch's official API servers. It is never shared with the developer, advertisers, or any other third parties.

## 4. User Consent
By installing and using the Extension, you consent to this limited access of your Twitch authentication cookie for the stated functionality.
