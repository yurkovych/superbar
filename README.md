# Twitch Superbar

Replaces standard sidebar with a new one that:
* **Shows only live channels you follow**
* **Overrides cap of 12 live channels you follow**
* **Removes recommendations from sidebar**

### ⚠️ Important stuff:
* **You must be logged in** for the extension to work
* **Works best with dark theme**
* **Does not support extended sidebar mode**, only collapsed where you see channels icons
